# MVP-09 設定画面と作業を邪魔しない表示

## 操作・仕様

トレイ/キャラ右クリックの「設定…」で専用ウィンドウを開く。1枚だけ再利用し、閉じても常駐アプリは終了しない。日常表示に固定ボタンは増やさない。

| 項目 | 動作 |
| --- | --- |
| 常に手前に表示 | 最前面を即時切替。トレイ項目とも同期 |
| キャラクターのサイズ | 50〜200%、25%刻み。画面内に収まる範囲で反映 |
| 自発的なセリフ | 起動/OS復帰の受動挨拶をON/OFF。OFFでもクリックへの返事は残す |
| 起動時にキャラクターを表示 | OFFなら次回はトレイだけで起動。トレイ/設定から再表示可能 |
| 動きとセリフを一時停止 | 残り時間を保持して進行を止め、吹き出し/一時表情・クリック反応・交流加算を停止 |
| キャラクターを非表示/表示 | 一時的な表示切替。非表示中は進行も止まり、再表示で残り時間から再開 |

一時停止も保存する。非表示操作自体は一時的で、次回は「起動時にキャラクターを表示」に従う。停止/非表示中でもトレイの設定・表示・終了を利用でき、表示中のドラッグと右クリックは残す。OSスリープ・非表示・一時停止が重なっても、理由がすべて解消するまで勝手に再開しない。非表示中もアプリ稼働時間として数え、OSスリープは従来どおり除外する。

新しい定期会話タイマーは追加しない。自発セリフの対象は既存の起動/復帰挨拶で、ONに戻しただけでは強制表示しない。OFFにした際は受動挨拶だけを消し、クリックへの返事は消さない。

## サイズ・保存・権限

吹き出しの文字サイズと上部112 DIPを維持し、立ち絵の基準340×468を倍率に応じて変更する。小サイズでも吹き出し用の幅340 DIPを確保。可能なら横中心・足元を維持し、画面が狭ければ補正する。要求200%でも実サイズは画面で制限される。描画とアルファ判定は同じcanvas変換を使い、再表示では入力状態を再評価する。

既存v1の未定義項目にshowOnStartup=true/paused=falseだけを補い、親密度・回数・他の設定は維持する。Mainで既知キー/型/scale範囲を検証し、既存の500ms集約/終了時保存へ接続。revision付き通知でトレイとUIを同期し、古い応答で新しい状態を戻さない。

設定画面は専用PreloadのgetState/update/setVisible/onChangeのみを公開。記憶・交流・ドラッグAPI、Node.js、任意パスは渡さない。IPCは設定用webContentsのmainFrameを照合する。両画面ともNode無効/contextIsolation/sandbox、遷移/追加ウィンドウ拒否、CSPを維持。設定Preloadはsandboxでローカルrequireが不要な単独bundleとする。新規依存・外部通信なし。

## 自動検証（ローカルmacOS）

- `npm run check`: lint/format/単体テスト65件/型チェック/ビルド成功。
- 追加6件: 値/型/未知キー拒否、旧セーブへの既定値補完、拡大縮小時の足元/中心と画面内補正、重複停止理由、明示pause/stopの維持、受動挨拶だけの非表示。
- `npm run test:settings`: 一時保存先の実Electronで設定UIを操作。最前面解除、75%の寸法と足元維持、挨拶OFFでのクリック返信、停止時の吹き出し消去、suspend/非表示/停止解除/resumeの重なりを確認。1枚の再利用、閉じても常駐継続、不正パッチ拒否、Node/キャラAPI非公開も検証。
- 同テストの2回目の実プロセス起動で、75%・最前面OFF・挨拶OFF・起動非表示・停止ONを復元。キャラを表示せず設定を開き、再表示/再開できることを確認。
- 設定画面の描画キャプチャを確認し、項目・ボタン・状態文が欠けずに収まることを確認。
- `test:memory/test:smoke/test:styles/test:character` も成功し、既存の保存/初期化/入力/トレイ/頭上吹き出し/小春5表情を維持。

IPC拒否エラーは意図した負テスト。普段のデータは変更しない。DOM操作・入力送出・描画キャプチャと実マウスの手動操作は区別する。実マウス/キーボード、実OSスリープ、Retina/外部画面、Windows実機は未実施。

## 手動確認（未実施）

1. `npm run dev`。トレイ/右クリック→「設定…」。再度開いても1枚、閉じてもキャラとトレイが残ることを確認。
2. 最前面と50/100/200%を切替。絵が歪まず、頭上吹き出しが顔に被らず、透明部/実画素の判定とドラッグが合うことを確認。外部画面でも比較する。
3. 自発セリフOFFで再起動し、挨拶は出ないがクリックには返事することを確認。
4. 停止で動き/反応が止まり、非表示でもトレイから戻せることを確認。非表示中の停止解除やスリープ復帰で意図せず再開しないことを確認。
5. 起動表示OFF・停止ON等を保存して再起動。トレイから表示/停止解除で戻せること、Tab/Space/矢印キーで操作できることを確認。
