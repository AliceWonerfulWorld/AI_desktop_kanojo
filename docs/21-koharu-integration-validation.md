# Issue #22 小春5表情の統合・検証

## 変更

mainに配置済みのユーザー選定PNG5枚を、既存 `CharacterRenderer` に登録。原画像は変更しない。通常アプリの `assets.ts` と `manifest.json` は小春のみを参照し、幾何図形を `test-assets.ts` / `test/manifest.json` に分離。テストPNGと生成スクリプトは保持する。

neutral/shy/sleepy/surprised/affectionateは別々の画像。smileは小春neutralへ代替。各行動に専用全身ポーズはなく、意味上の行動と表情を維持してidle画像を使う。甘えは新しい首かしげの画像で、shyの流用ではない。画面読み上げラベルとステータスもテスト素材表記から更新。

3072×5500の4枚を読むため画素上限を1600万から1800万へ調整し、無制限にはしない。元画素のアルファのみを保持してヒット判定のRGB保持を省く。全5枚の背景・脚の間の透明性と、実画素の入力を検証。セキュリティ設定・IPC・自律行動・関係性ロジックは変更しない。

## 素材検査

寸法、RGBA、透明/不透明画素数、外接範囲と出典・許諾状況は [小春素材台帳](../assets/character/koharu/manifest.md)。全5枚をローカル画像プレビューで確認。白背景矩形はなく、全身と足元は収まる。甘えはファイル名と異なり1143×2047で、半透明画素が多いことを記録した。髪輪郭の明るい細線の原寸検査、白フリンジの最終判断は未実施。

5枚のcanvas出力は異なり、340×520描画の外接範囲差は2canvas画素以内。ポーズと顔の差はあるため、画素単位の差分素材とは扱わない。Mac実アプリの切替が自然かは未確認。

## 自動検証（ローカルmacOS）

- `npm run check`: ESLint / Prettier / 単体テスト51件 / 型チェック / ビルド成功。PNG5枚の実デコード、異なるハッシュ、RGBA、透明余白・脚の隙間、全24状態の候補とsmile代替を追加。
- `npm run test:character`: 既存の幾何図形テストをテスト専用データで維持。実小春の5表情描画、全24状態、透明余白/脚の隙間/胴体の判定、外接範囲、familiarのクリック反応でshy表示→3秒後にreading/neutralへ復元を確認。
- `npm run test:smoke`: 本番ビルドの起動状態が小春素材であること、透明→胴体→脚の隙間→靴の入力切替、透明部分のドラッグ/メニュー抑制、実画素のクリック/ドラッグ/右クリック、連打抑制、トレイ・最前面・非表示/復旧・終了を確認。旧テストの胴体座標(170,312)は小春の脚の隙間なので、実画素(170,260)に変更した。
- `npm run test:styles`: 開発/本番CSS、段階別挨拶と開発確認API成功。
- ビルド出力は小春5PNGを含み、テストPNGを通常ランタイムへimportしない。

自動入力・模擬時計/カーソルによる確認であり、OS越しの実マウス、別アプリへの実クリック到達、Windows実機を検証済みとは扱わない。

## 手動確認（未実施）

Macの画面操作接続が利用できず、実アプリの目視・実マウスは未実施。以下を確認する。

1. `npm run dev` で小春が表示され、幾何図形が出ないことを確認。開発者ツールで `behaviorPreview.pause()`。
2. `await characterPreview.setState({ action: 'idle', expression: 'neutral' })` の表情をshy/sleepy/surprised/affectionateへ切替。顔と全身、足の接地、左右位置の跳ね、明るい/暗い背景で輪郭・白フリンジを比較。甘えの半透明感も確認する。
3. smileが小春neutralで代替され、幾何図形が出ないことを確認。`relationshipPreview.setAffection(30)`、reading/neutralにしてクリックすると、照れなどの短い反応から約3秒後に戻る。
4. 透明余白と脚の間で背後の安全な画面をクリックでき、胴体では短いクリック・ドラッグ・右クリックが可能か確認。透過OFFでも透明部分のドラッグ/キャラメニューが始まらないことを確認。
5. `behaviorPreview.resume()` で自律進行へ戻し、時間帯/行動で幾何図形に戻らないことを確認。トレイの非表示/再表示、最前面、位置復旧、終了も確認。
6. `npm run build` → `npm run start` の本番でも表示を確認。Retina/外部画面/混在DPIで輪郭と入力領域を比較。

公開・商用・成人向け配布の許諾が未確認のため、リリース可能とは報告しない。高解像度デコードとキャッシュの常駐メモリ負荷も実測課題として残る。
