## 2. Live2D用PSDパーツ（P1）

以下は初期の**設計チェックリスト**。実際の分割数は、まばたき・顔の向き・体動作等の希望によって変わる。

| ID | パーツ群 | 細分化例 | 主な用途 |
| --- | --- | --- | --- |
| L2D-01 | 顔・輪郭 | 顔輪郭、耳、首、肌の重なり | 顔向き |
| L2D-02 | 目（左右個別） | 白目、虹彩、瞳孔、上/下まぶた、まつ毛 | 目線、瞬き |
| L2D-03 | 眉（左右個別） | 左眉、右眉 | 表情 |
| L2D-04 | 口 | 上下唇、口内、歯・舌（必要なら） | 口開閉、笑顔 |
| L2D-05 | 髪 | 前髪、左右横髪、後ろ髪、毛束 | 髪揺れ |
| L2D-06 | 胴体・服 | 首元、胴体、服の前面・背面・袖 | 呼吸、体の傾き |
| L2D-07 | 腕・手 | 左右の上腕・前腕・手、必要なら指 | 手振り |
| L2D-08 | 追加表情 | 赤面、涙目、光彩変更等 | 照れ・甘え |
| L2D-09 | 小物 | マグカップ、本等 | 生活演出 |

- 髪や服の下など見えない部分は**描き足す**。
- ひとつの完成PNGを単純に切っただけでは動作時に穴が生じやすい。
- **素材分け用PSD**と**Cubismインポート用PSD**を別ファイルで管理する。
- 1パーツ1レイヤーを基本に、各パーツの線画/塗り/影を適切に結合。RGB/sRGBで保存する。
- モデルデータ(.moc3等)とモーションはPSDとは**別の成果物**。
- 公式: https://docs.live2d.com/cubism-editor-manual/divide-the-material/

## 4. 生成・編集・納品ファイルの推奨構成

```text
assets/
└── character/
    ├── reference/          # 確定デザイン、表情基準
    ├── png/                # MVP/フォールバック用透過画像
    ├── source/             # 生成原画・手修正用ソース（商用権利確認済み）
    ├── psd/                # 素材分けPSD・インポートPSD
    ├── live2d/             # model3.json、moc3、テクスチャ等（権利確認後）
    └── manifest.md         # 各ファイルの生成元/用途/権利/状態
```

第三者に配布・公開できない素材や大容量の制作データは**公開GitHubへコミットしない**。個別の管理領域に保存し、READMEやmanifestに入手/ビルド手順を記す。

## 5. 品質確認（生成素材共通）

- [ ] 成人女性として自然に見える
- [ ] 顔、髪型、瞳色、服装がマスター画像と一致
- [ ] 手の指、脚、衣装の重なりに破綻がない
- [ ] 全身画像の頭・足先が欠けていない
- [ ] 背景透過とアルファ境界がきれい
- [ ] 常駐時の小サイズでもキャラが識別できる
- [ ] 高解像度で必要部分が崩れない
- [ ] 生成サービス・モデル名・利用条件・生成日を記録
- [ ] 配布/成人向け/商用利用の可否を確認
- [ ] Live2D PSDの各パーツが独立し、見えない部分が補われている

## 6. 制作順

1. **REF-01は選定済み**。基準画像ファイルを保存し、生成日時・作成元を記録する
2. REF-02、IMG-01〜04をマスター参照で生成
3. ElectronのPNG表示・反応・自律行動を検証
4. IMG-05〜08と簡易モーションを追加
5. Live2D向けPSD分割とCubismテスト
6. 衣装・特別演出・販促画像を追加
