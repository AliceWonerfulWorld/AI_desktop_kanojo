# MVP-08 生活記憶と設定のローカル保存

> MVP-09更新: 設定画面、サイズ、自発挨拶、一時停止、起動時表示を実装。v1の未定義showOnStartup=true/paused=falseを補い、既存記憶を引き継ぐ。以下の「次回は表示」「変更UIは#9」はMVP-08時点の履歴で、現在は保存した起動時表示に従う。[現行の操作・検証](23-settings-validation.md)。

## 保存・復元

MainだけがElectronの `userData` 内の `memory.json` を読み書きする。ネット送信は追加しない。Rendererへファイルパスや任意の保存値を書き込むAPIは渡さない。親密度0〜100、関係ステージ、最終起動日時（UTC ISO文字列）、累計実稼働ms、交流回数、最後の行動、受付/加算の残り待ち時間、ウィンドウ位置・寸法と設定をschemaVersion=1で保存する。

現在操作できる設定は「常に手前」と「クリック透過」。表示サイズscale=1・自発セリフ=trueの値もスキーマに保持するが、その変更UIと機能拡張は #9。隠したまま終了しても次回は表示して操作導線を確保する。保存位置は現在の画面作業領域へ補正し、取り外した画面や画面外から復旧する。

親密度と段階は保存値の整合を検証する。受付済みの交流はRendererから通知するが、Mainで同じウィンドウのメインフレームか・直前にMainが短いクリックと認めた操作かを確認し、1回だけ受理する。通常3秒/睡眠15秒の交流受付、親密度60秒に1点の制限はMainで適用。残り待ち時間も保存するため、再起動やRenderer再読み込みで加算を稼げない。待ち時間は実稼働のみで減り、スリープ・未起動期間のまとめ加算や減点はない。

起動後は保存した親密度から段階別反応を復元する。最後の行動は新しい継続時間で再開し、未起動の間に行動が進んだと推測しない。保存行動がsleepingで現在は深夜以外なら、現在時刻のポリシーで選び直す。初回の挨拶マーカーは既存データを引き継ぐ。

累計時間はMainの単調時計だけを使う。起動ごとに基準時計を取り直し、最終起動日時との差は加算しない。powerMonitorのsuspendで積算を止め、resumeで新しい基準へ戻す。重複通知で二重加算しない。非表示中はアプリ稼働として数える。OS通知を取りこぼす環境での実スリープは実機確認が必要。

## 書込・復旧

- 更新は500msでまとめ、稼働中は30秒ごとにもチェックポイントを保存する。終了時は新規受付を止め、保存キューと最終保存を待って終了する。
- 一時ファイルへ書込、ファイルsync、同じディレクトリでrenameする。書込は直列化し、前回の正常な内容を `memory.json.bak` に保持する。中途半端な `.tmp` は起動時に採用しない。
- 64KiBを超えるファイル、JSON不正、範囲外、型不正、未対応バージョンを拒否する。破損/未対応データは `.invalid-<UUID>` に退避して残し、正常なバックアップから復旧。両方無効なら初期状態で起動し、復旧/初期化したことをダイアログで通知する。v1より前の生活記憶セーブはなく、既存の空マーカーだけを継続する。
- 保存失敗はセッション中に一度ダイアログで知らせる。保存先の読込や退避自体が不可能な場合は、既存データを無視して上書きせず起動を中止する。
- 強制終了では直近の未保存変更や最大約30秒分の稼働時間が失われ得る。バックアップ復旧時は前回保存へ戻る。停電・ストレージ障害全般の無損失を保証するものではない。

## データの初期化

トレイ/右クリックの「生活記憶・設定を初期化…」で確認画面を開く。既定選択とキャンセルは「キャンセル」。明示的に「初期化する」を選んだ場合のみ記憶・バックアップ・一時ファイル・退避データ・旧挨拶マーカーを削除し、初期状態を保存して表示を再読込する。画像、キャッシュ等の他ファイルは削除しない。初期化中の重複実行を防ぎ、終了処理は初期化の完了も待つ。

## 自動検証（ローカルmacOS）

- `npm run check`: ESLint / Prettier / 単体テスト59件 / 型チェック / ビルド成功。
- 追加8件: 型/値/バージョン検証、連続保存と別インスタンスでの読込、破損/未対応ファイルの退避・バックアップ復旧・両方破損の初期化、書込失敗時の正常ファイル維持と再試行、所有ファイルだけの削除、重複suspend/resume、未起動時間の除外、再起動後の待ち時間、連打/上限/段階、睡眠受付、保存行動の最初の再開を確認。
- `npm run test:memory`: 一時userDataで実Electronを4回起動。クリック権限のないIPCを拒否、正しい短いクリックで1点/1回、保存終了後の再起動、固定70点のclose挨拶・readingの復元、位置/最前面/透過の復元、2000年の最終起動日時でも未起動時間を加算しないことを確認。初期化キャンセルは維持、実行後は次のプロセスでも0点/0回、初回マーカーを確認。
- `npm run test:smoke`: 既存のクリック/ドラッグ/透明部/連打/右クリック/トレイ/表示復旧/終了成功。
- `npm run test:character`: 小春5表情、全状態代替、3秒復元、アルファ判定等の既存検証成功。
- `npm run test:styles`: 開発/本番の頭上吹き出しとDEV用親密度確認成功。

再起動テストは一時ディレクトリだけを使用し、普段の生活記憶を初期化しない。実マウス、実OSスリープ、Retina/外部画面、Windows実機、電源断は未実施。Windows/macOS CIで同じコマンドを実行する。

## 手動確認（未実施）

1. `npm run dev` で起動。短くクリックし、Consoleの `await desktop.getMemory()` でaffection・interactionCount・totalActiveMsを確認。直前の反応から通常3秒/睡眠15秒以内だと保存側で再受付しない。
2. 位置を動かし、最前面/透過を切り替え、トレイの「終了」で終了。再起動して位置・設定・親密度・交流回数が引き継がれることを確認。未起動の時間分だけtotalActiveMsが増えていないことを確認。
3. OSスリープから復帰して、スリープ分の時間が増えていないことを確認。動作中は非表示でも稼働として数える。
4. 初期化を使う場合は消えてよい記憶だけで実施。キャンセルで維持、実行後に親密度・回数・設定が初期状態となり、再起動後も戻らないことを確認。

DEVの `relationshipPreview.setAffection` は表示確認用で、保存値を書き換えない。クリック後はMainの保存値に戻るため、MVP-07当時の「29を設定してクリックで30へ」の手順は使用しない。保存を含む閾値検証は一時ディレクトリの固定セーブを使う自動テストで行う。本番にDEV用の値変更APIを追加しない。
