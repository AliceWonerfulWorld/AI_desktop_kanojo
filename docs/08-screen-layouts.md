## UI-01: 日常常駐ウィンドウ
```text
              ┌──────────────────────┐
              │「今日は何を読もう？」│  ← 吹き出し・短時間のみ
              └──────────────────────┘
                    ╭──────╮
                    │ 2D   │
                    │ 彼女 │  ← 通常はキャラだけ表示
                    │      │
                    ╰──────╯
※実際には枠線・背景・タイトルバーなし。周囲は透明。
```

### 画面構成案
- 初期表示: 主ディスプレイ右下、タスクバー等を避けた作業領域内。
- 暫定ウィンドウ寸法: **340×520 論理px程度**（後で調整）。
- キャラ表示: 下寄せ・縦横比保持。PNGでもLive2Dでもレイアウトを維持。
- 吹き出し: 最大240px幅、1〜2行、4〜6秒で消える目安。画面端からはみ出さない。
- 何もしない時は数値・好感度バー・メニューを常設しない。
- 自律行動: 待機・読書・休憩・睡眠。時刻によって変化。

### 操作ルール
| 操作 | 反応 |
| --- | --- |
| キャラを左クリック | 表情差分・ひとこと表示 |
| キャラを左ドラッグ | ウィンドウ移動、終了時に位置を保存 |
| キャラを右クリック | ネイティブメニュー |
| トレイを操作 | 表示/非表示・設定・終了 |
| 透明領域をクリック | 背後の操作を妨げないことを**目標**。非矩形ヒットテストは技術検証で可否決定 |

- クリック/ドラッグの判別は移動閾値案6pxから試験。
- CSSの透明化だけではOSにイベントは透過しない。
- Live2Dモデルの場合、WebGLキャンバスの輪郭とクリック判定の対応を追加検証。
- 不意に成人向け表現を表示しない。将来も明示的なモード変更を必要とする。

## UI-02: 設定ウィンドウ
```text
┌────────────────────────────┐
│ 設定                       │
│  表示                      │
│  ☑ 常に手前に表示           │
│  サイズ [────●────]         │
│                            │
│  会話                      │
│  ☑ 自発的なひとり言         │
│                            │
│  [キャラを非表示] [閉じる]  │
└────────────────────────────┘
```
- 通常の設定ウィンドウで実装。約420×400論理pxを仮の初期値にする。
- 設定変更は即座に反映・再起動後も復元。
- キーボード操作、見やすいラベル、最前面解除を考慮。

## UI-03: 交流・イベントウィンドウ（将来）
```text
┌──────────────────────────────────────┐
│                            [閉じる] │
│      [背景・Live2Dまたは立ち絵]      │
│                                      │
│  ┌────────────────────────────────┐  │
│  │ 彼女                           │  │
│  │ 「今日も一緒にいてくれたね。」 │  │
│  │                            ▼   │  │
│  └────────────────────────────────┘  │
│ [ログ] [オート] [スキップ] [設定] [戻る] │
└──────────────────────────────────────┘
```
- 初期寸法案960×540論理px、16:9、リサイズ可。
- 半透明テキストボックス、名前欄、読める行間、文字＋アイコンのボタン。
- 詳細なADVエンジン、ログ、オート、スキップは販売版で実装。
- イベント中に通常のひとり言がイベント画面を邪魔しない。
- イベント終了後は日常モードへ戻る。

## UI-04 / UI-05 メニュー
- 右クリック: 設定、最前面表示の切替、非表示、終了。交流する項目は実装後に追加。
- トレイ: 表示/非表示、設定、終了。
- どの状態からでも終了操作へ到達できるようにする。

## 仮の配色
- 文字/深い背景: `#243042`
- 淡い背景: `#F7F4F0`
- ソフトなアクセント: `#D99AA7`
- イベントテキストボックス: `rgba(30,38,51,0.88)`
- 立ち絵の存在感が主役。デザインの模倣は行わない。
