## 2. UI-01 日常（現行の記録）

```text
デスクトップ（常設のメニューや好感度バーなし）
                     上部112 DIPの予約領域
                   ┌──────────────────┐
                   │ 短い吹き出し     │ ← 幅最大240 / 14px
                   └────────┬─────────┘ ← 下端は描画領域の6px上
                            ▽
                  ┌────────────────────┐
                  │      小春PNG       │ ← 基準340×468 DIP
                  │     全身・透過     │    縦横比保持
                  │                    │
                  └────────────────────┘
※説明枠は表示されない。全体基準340×580 DIP。
  左クリック＝ひとこと / ドラッグ＝移動 / 右クリック＝メニュー
  吹き出し自体はマウス操作対象にしない。
```

基準位置は主画面の右下、保存位置があれば復元し作業領域内に補正。サイズ50〜200%は立ち絵に適用し、吹き出し文字と112 DIPの予約は維持する。起動/復帰挨拶5秒、クリック反応3秒。短文は1〜2行を目安とし、現行高さ88pxは3行分相当まで。超過を黙って切る現行スタイルをイベント長文へ流用しない。

### UI-04/05 既存メニューと提案入口

```text
実装済みの共通メニュー        追加する場合の候補（未実装）
 設定…                       お話・イベント… → 一般向け一覧
 表示 / 非表示               ※追加位置は要承認
 常に手前に表示 ✓
 透明領域をクリック透過 ✓     成人向け入口は設定内だけの案。
 動きとセリフを一時停止       日常吹き出しやトレイ通知には出さない。
 主画面の右下に戻す
 開発者ツール
 生活記憶・設定を初期化…
 終了
```

右クリックとトレイの実装は共通メニュー。新規「お話・イベント…」を追加すればトレイにも入口が現れるが、クリックしただけでイベント開始にはしない。一般向け一覧で明示的に開始する。非表示/終了/最前面解除は残す。成人入口の置き場所を変える場合も自己申告を省略しない。

## 3. UI-02 既存設定とUI-06追加案

```text
既存440×620 DIP（内容はスクロール可能）
┌──────────────────────────────────┐
│ 小春との暮らし / 表示の設定       │
│ 作業に合わせて、ちょうどいい距離に。│
│ □ 常に手前に表示                 │
│ サイズ [────●────] 100%           │
│ □ 自発的なセリフを表示           │
│   起動・復帰時の挨拶…            │
│ □ 起動時にキャラクターを表示     │
│ □ 動きとセリフを一時停止         │
│ [キャラクターを非表示] [閉じる]   │
│ 設定は自動で保存されます。       │
└──────────────────────────────────┘
```

既存設定の順序・保存・単一ウィンドウを維持。以下は設定末尾に追加する**別セクション案**であり、既存画面の作り直しではない。

```text
衣装（一般向け）                          ← #37
 (●) 普段着          選択中
 ( ) 部屋着          桜の小花柄パジャマ
     準備中：素材が未配置の間は選択不可
 [適用中… / 読込失敗：普段着を維持しました]

物語                                     ← #29/#30
 [お話・イベントを選ぶ…]
 [成人向け専用モードの確認へ…]             ← 中立ラベルのみ
```

衣装はラジオ選択の明示確定で即時適用・保存する案。上下キーで候補フォーカスのみを変え、Space/Enterで確定する設計を #37 で検証する。既存設定と同じ「自動保存」説明を使い、余分な保存ボタンは増やさない。画像準備中/失敗/選択中を区別する。部屋着の不足表情は同衣装のneutralへ代替し、衣装を勝手に普段着へ戻さない（未知IDの保存復旧は #37 の仕様）。プレビュー画像は必須にせず、未存在素材をサムネイルで示さない。

## 4. UI-03A 立ち絵重視案（提案）

検討用の外寸960×640 DIP。固定比率にはしない。左側に全身PNG、右側に独立した本文・選択肢の面。CGノード時は左を画像領域として使い、重ねて小春PNGを二重表示しない。

```text
┌────────────────────────────────────────────────────────┐
│ お話・イベント                  [日常へ戻る] [非表示] │
├─────────────────────┬──────────────────────────────────┤
│                     │ 小春                             │
│      小春PNG        │ 本文を複数行で表示する。           │
│    （全身優先）     │ 長文はこの欄でページ分割する。     │
│                     │                           1 / 2  │
│  CG時は画像に置換   │ [次へ →]                         │
│                     ├──────────────────────────────────┤
│                     │ 選択してください（選択待ち時）   │
│                     │ [選択肢A：2行以上でも全文を表示]  │
│                     │ [選択肢B]                        │
├─────────────────────┴──────────────────────────────────┤
│ [ログ ※#32導入後] [設定]           状態：選択待ち       │
└────────────────────────────────────────────────────────┘
```

本文と選択肢は同じ場所で入れ替えず、読み返しながら選べる。本文の未読ページがある間は選択を有効にしない。最後のページで選択待ちなら「次へ」を無効にし、理由を状態欄に表示。CGはcontainで全体保持、余白は面色で埋める。

## 5. UI-03B イベントCG重視案（提案）

検討用の外寸960×540 DIP/16:9。比率・寸法は未確定。画像領域と本文領域を分け、文字は不透明な下部パネルに置く。CG全体を優先し、本文をCGへ常時重ねない。

```text
┌────────────────────────────────────────────────────────┐
│ お話・イベント                  [日常へ戻る] [非表示] │
├────────────────────────────────────────────────────────┤
│                                                        │
│              CG / 背景＋小春PNG（CGなし時）             │
│                 contain・無断トリミングなし             │
│                                                        │
├────────────────────────────────────────────────────────┤
│ 小春                                                   │
│ 本文を読みやすい幅で表示。                    1 / 2     │
│ [選択肢A（複数行）] [選択肢B（狭い時は縦積み）]        │
│ [ログ ※#32導入後] [設定]                     [次へ →] │
└────────────────────────────────────────────────────────┘
```

CGは本文領域を除く空間で全体を表示する。選択肢が多い場合は画像を縮め、選択肢欄を縦スクロール可能にする。CGを拡大する機能・本文を隠す機能は #33 等への追加検討とし、初回イベントには必須にしない。一般/成人どちらにも同じレイアウトを使え、内容をモードで分離する。

## 6. 2案の比較と推奨の位置付け

| 論点 | A: 立ち絵重視 | B: CG重視 |
| --- | --- | --- |
| 主役 | 小春の全身と会話の距離感 | 場面の一枚絵と物語 |
| 利点 | 本文と選択肢を縦に確保、PNG中心で比較しやすい | 横長CGの見せ場が分かりやすく、操作欄が下に集まる |
| 欠点 | 横長CGが小さくなり、左右で視線移動が増える | 低い画面では画像領域が圧迫され、長い選択肢に工夫が必要 |
| 長文/大きい文字 | 右側の高さを使えるが横幅不足に注意 | 下部面の拡張で画像が小さくなる |
| 素材未提供 | 左に既存PNG、CG欠損なら中立代替 | 上に既存PNG、CG欠損なら中立代替 |
| 適した比較場面 | 日常寄りの短編・対話 | 初回イベントのCG提示 |

レビューの出発点として **Aは会話中心、BはCG中心**の候補。どちらも正式採用していない。ノードごとに両レイアウトを切り替えると実装・検証が増えるため、最初の #30 ではユーザーが選んだ1案を基準にする提案。960×540/16:9を既定の決定事項にはしない。

## 7. UI-07 確認と補助画面（提案）

```text
専用モードを開く前の確認（一般向け背景・画像なし）
┌────────────────────────────────────────┐
│ 成人向け専用モード                     │
│ 18歳以上の方のみ利用できます。         │
│ □ 私は18歳以上です（自己申告）         │
│ [キャンセル] [専用モードを開く]         │
└────────────────────────────────────────┘
初期フォーカス＝キャンセル。未チェックでは開けない。

一般/専用のイベント一覧（同じ枠組み、データは分離）
 [利用可能なイベント名] [開始] / [続きから]
 [未解放：条件未達]  ※専用画像・ネタバレを通常一覧に出さない
 [日常へ戻る] [非表示]

ログ（#32導入後）
 [ログを閉じる] → 開く前の本文・選択位置へ
 話者 / 表示済み本文 / 選択結果をスクロール
 ※履歴を押しても分岐を巻き戻さない
```

専用モード中は「日常へ戻る」「非表示」を上部に常設し、ログ・エラー・設定からも同じ退出手段へ到達可能にする。Escは専用モードを一段で離脱する案。未実装のログ/オート/スキップ/回想ボタンを先に並べない。エラーは「画像を表示できません」「日常へ戻る」など中立な表示にし、専用画像のファイル名を日常へ出さない。
