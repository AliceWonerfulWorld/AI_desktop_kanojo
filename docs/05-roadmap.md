## デモのストーリー（例: 90秒）
1. デスクトップの端に彼女がいる。
2. 今は本を読んでいて、時々こちらを見る。
3. クリックで一言返事し、表情が変わる。
4. テスト用の時刻を変えると眠る（実装時に開発者用モードで再現）。
5. アプリを終了・再起動すると交流記録が残っている。

## 優先順位の原則
- **最優先**: 透明表示 + 表情/動作 + 自律行動 + 再起動時の復元
- **次点**: 関係性・設定の使いやすさ
- **後回し**: AI会話・音声・Live2Dの高度なリギング・成人向け本編
