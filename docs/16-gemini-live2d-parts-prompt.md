# Gemini向け — Live2D用PSDパーツ分け指示・実行プロンプト

> 対象キャラ: **小春**。入力は採用済みマスター画像と現在の自然立ち（`koharu_normal.webp`）。
> 目的は**Live2D制作を前提としたパーツ分け案と分離素材の生成補助**。GeminiにPSD/Live2D完成を装って報告させず、実際の画像出力の品質を確認しながら進める。

## 0. Geminiに読み込ませるもの

必須:
1. 採用済み小春の**手を振るマスター立ち絵**（外見の正本）
2. 追加生成した**自然立ち通常表情 `koharu_normal.webp`**（パーツ分けのベース）
3. [小春マスターデザイン](14-koharu-master-design.md)
4. [小春素材台帳](../assets/character/koharu/manifest.md)

必要に応じて:
- `koharu_shy.webp` / `koharu_sleeping.webp` / `koharu_suprising.webp` / `koharu_sweet.webp`（顔表情の参考）
- [パーツ仕様](12-character-assets.md)
- [Live2D導入計画](09-live2d-plan.md)

**現行WebPは572×1024px、RGB・背景不透明**。高解像度元画像が存在するなら、そちらを優先。小さな画像の単純拡大は、隠れた部分や瞳・口のレイヤーを自動生成するわけではない。

## 1. STEP A：まず「分割設計」だけ回答させる（画像は生成しない）

以下の内容をGeminiに送る。

```text
あなたはLive2D Cubismモデル制作に向けた2Dイラスト素材分けの制作補助です。
添付の小春の承認済みマスター画像をキャラクターの外見正本、
自然立ち通常画像をパーツ分けベースとして扱ってください。

小春は23歳設定の成人女性。色白で華奢、温かい琥珀色の目、
ライトブラウンの高いサイドポニーテール、ピンクの花飾りと
クリーム色のリボン、クリームの編みカーディガン、ピンクのトップス、
白いショートパンツ、ピンクのリボンチョーカー、
腕時計、フリル靴下、ミント色のスニーカーが特徴です。

現段階では画像を生成せず、次の項目を具体的に整理してください。

1. 全身Live2Dモデルで動かすのに必要なPSDレイヤー名一覧
2. 親子関係（頭、顔、左右目、眉、口、髪、胴体、腕、脚、小物）
3. 前後関係（前に来るもの、後ろに隠れるもの）
4. 元のイラストに存在しない「描き足し」箇所
5. 最初の実装目標：呼吸、まばたき、視線、笑顔、照れ、甘え、
   髪とリボンの軽い揺れ、首かしげ
6. 各モーションのために最低限必要なパーツ
7. 制作工程を「最優先 / 余力で追加 / 今回対象外」に分ける
8. 各パーツの切り出し時に起こる問題（穴・白フチ・陰影の断絶等）

JSONではなく、見やすいMarkdownの表で出してください。
一度の生成で完成PSDが作れると仮定しないでください。
```

## 2. STEP B：まず顔と髪のパーツから始める

設計書を確認したら以下のプロンプトを送る。**一度に全身を大量生成しない。**

```text
今度は小春の自然立ち通常画像を参考に、Live2D用の
「顔と髪」の独立パーツ制作を補助してください。

最初に制作するパーツは次の順番です:
1. 顔の肌ベース（前髪の下の額・髪で隠れた輪郭まで描き足す）
2. 右目と左目の白目、虹彩、瞳孔、ハイライト
3. 右目と左目のまつ毛、上まぶた、下まぶた
4. 右眉と左眉
5. 口周辺（閉じ口、開口の口内、上下の線画）
6. 前髪、左右の横髪、おくれ毛、後ろ髪
7. サイドポニーテールの根元・中間・毛先
8. ピンクの花飾り、クリーム色リボンの結び目と左右の垂れ

絶対条件:
- 同じ小春の顔・色・描線・髪型・目の色を変えない
- レイヤーは後でPSDに組み立てるので、パーツ単位で独立させる
- 各パーツは元画像と同じキャンバス座標・サイズを維持する
- 背景は本当に透明なRGBAを希望。白い背景を透明と偽らない
- 見えない部分は自然に補完し、継ぎ目に穴が出ないようにする
- 文字・説明・仕切りを絵の中へ書かない
- 1枚のイラストやパーツ一覧のコラージュは
  PSDの独立レイヤーとして使えない。可能な場合は
  1パーツごとに透過PNGを分けて出力する
- 画像生成機能で個別ファイルが出せない場合は、その制限を明示して
  パーツごとの追加生成指示や修正箇所を文章で返す

まず「顔の肌ベース」1パーツだけ作成してください。
完成後に私が確認してから次に進みます。
```

## 3. STEP C：体・衣装・脚に拡張

顔と髪が合格した後に1パーツずつ進める。

```text
先ほど作った小春の顔・髪のベースデザインを維持し、
同じキャンバス座標系でLive2D用の胴体・衣装・腕・脚を
分割できるようにしてください。

分割候補:
- 首・胴体・左右肩、上腕・前腕・手
- カーディガン本体・左右袖・ボタン
- ピンクのトップス・胸元のリボン・リボンチョーカー
- ハイウエストショートパンツ・ベルト
- 左右太もも・膝下・靴下・靴
- 腕時計

出力は1パーツずつ、同じキャンバス上の適切な座標で、
背景透明のRGBA画像を希望します。
袖の下、髪の下、服の下など動かした際に見える部分は
必要最小限を描き足し、キャラの姿を変えないでください。

まずは不足するレイヤー一覧と描き足し箇所を確認し、
作成する1パーツを提案してください。承認後に生成します。
```

## 4. STEP D：編集ツールでPSDを組み立てる

Geminiの出力が十分なら、画像編集ソフトで独立PNGを重ねてPSD化する。

- `koharu_material_separation.psd`: 編集可能な素材分け元（線画・色等を保持して良い）
- `koharu_import.psd`: Cubism取り込み専用。基本的に**各パーツを一枚のラスターレイヤーに統合**する。元PSDは上書きしない。
- **RGB、8bit/チャンネル、sRGB**、PSDのレイヤーマスクやクリッピングマスクは読み込み前に適切に統合。
- 一意なレイヤー名にする。不要な透明ゴミを取り除く。
- レイヤーの上下関係と隠れ領域を確認し、実際にCubism Editorへのインポートをテストする。
- `PSD作成済み` と `Cubismにインポートできる` と `Live2Dで動く` は別の完了条件。

## 5. 成果物の受け入れ基準

- [ ] 小春の顔立ち・髪・小物が元デザインと一致
- [ ] 同じサイズ・座標の透過パーツ画像になっている
- [ ] 全身の組み立て結果が基準画像と大きく違わない
- [ ] 髪・顔・袖の隠れ部分を補っても自然につながる
- [ ] 目開閉、口開閉、髪揺れに必要なパーツが独立
- [ ] 元PSDとCubism用PSDを分離して保存
- [ ] Cubism Editorに実際にインポートできることを確認
- [ ] ライセンス確認・生成AI利用記録を保持
