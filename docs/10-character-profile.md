## 1. キャラクターの核

**「いつも元気で明るい女の子。親しくなると、ふと甘えた一面を見せる。」**

デスクトップで自由に暮らし、ユーザーがいない時も読書やおやつ、休憩を楽しむ。最初から好意を押しつけず、付き合いが長くなると照れ笑いや控えめな甘えを見せる。**一緒に過ごす生活感が主役で、恋愛はその延長。**

## 2. キャラクター設定

| 項目 | 設定 | 状態 |
| --- | --- | --- |
| 名前 | 小春（こはる）、苗字は未定 | 仮 |
| 年齢 | **23歳の成人女性** | 提案 |
| 性格 | **元気・明るい・人懐っこい** | 合意 |
| 関係性の変化 | **親密になると甘えた一面を見せる** | 合意 |
| 体型 | **華奢で細身**、自然な成人のプロポーション | 合意 |
| 肌 | **色白**、頬に自然な血色 | 合意 |
| 髪 | ライトブラウン〜アッシュブラウン、**高めのサイドポニーテール**（淡い花飾りとリボン） | 外見確定 |
| 瞳 | あたたかいアンバー・はちみつ色 | 外見確定 |
| 衣装 | アイボリーのケーブル編みカーディガン、淡いピンクのトップス、白いショートパンツ、ミントのスニーカー | 外見確定 |
| 口調 | 明るく自然体。「やっほー！」「えへへ」など | 提案 |
| 趣味 | お菓子、紅茶、読書、音楽 | 提案 |
| 出身、誕生日、職業 | 未決定 | 未決定 |

**画像生成で重要:** 少女・幼児的な頭身ではなく、明確に20代成人女性として表現する。小柄・華奢さは成人らしい輪郭・服装とのバランスで表現。

## 3. 性格の三段階（内部名は既存仕様に合わせる）

| 内部stage | 距離感 | 表情・しぐさ | 台詞例 |
| --- | --- | --- | --- |
| stranger | 元気な知り合い | 快活な笑顔、手を振る | 「やっほー！ 今日も元気？」 |
| familiar | 気軽な友達 | よく目が合う、安心した笑顔 | 「あっ、来た！ ちょうどお話したかったんだ」 |
| close | 安心して甘えられる相手 | 照れ笑い、首かしげ、少し甘える | 「……もうちょっとだけ、一緒にいてもいい？」 |

- 好感度が上がっても「明るさ」は失わない。**甘える表情が増える**という変化にする。
- 起動しない期間のペナルティ・罪悪感を与える台詞はなし。
- タップ連打による急激な好感度上昇を避ける。

## 4. 生活演出（仮）

| 時間帯 | 気分 | 主な行動 | 台詞例 |
| --- | --- | --- | --- |
| 朝 | 眠いが前向き | あくび、伸び、挨拶 | 「おっはよー！ まだちょっと眠いけど！」 |
| 昼 | 元気・好奇心 | 読書、おやつ、ひとり言 | 「今日は何して遊ぼっかな〜」 |
| 夕方 | リラックス | 飲み物、軽いストレッチ | 「ふぅ〜、休憩しよっ」 |
| 夜 | 柔らかい雰囲気 | ゆったり過ごす、会話 | 「こういう時間、なんか好きだな」 |
| 深夜 | うとうと | 眠そうな目、就寝 | 「んん……おやすみ……」 |

※元の状態遷移エンジンの行動キー（idle/reading/resting/sleeping）を維持する。新しい動作や道具は後で追加。

## 5. デザインの共通ルール

- 清潔感、親しみやすさ、明るい笑顔。長時間画面に置いても疲れない配色。
- **華奢・色白・成人らしさ**を両立する。
- 構図は全身、正面〜軽い斜め。小さく表示した時の顔・髪・手の認識を優先。
- **採用元画像をマスターデザインとして固定**。高いサイドポニーテール、花飾り・リボン、琥珀色の瞳、クリームと淡いピンクの衣装を再現する。
- 日常モードは通常衣装。部屋着・パジャマ・甘え表情は段階的に制作。
- AIで生成した別表情や別衣装が「同じ人物」に見えることを品質の最重要指標とする。
- 特定の既存キャラや存命イラストレーターの画風のコピー指示を使わない。

## 6. UI/Live2D演技設計

承認済みの表情演技: **通常（明るい笑顔）、照れ、甘え**。今後追加する表情: 驚き、眠そう、満面の笑み。
理想のモーション: 呼吸、瞬き、口の開閉、視線、首かしげ、控えめな髪揺れ、手を振る。

大きなポーズ変更（座る、寝る、読書）は、同一Live2Dモデルで成立するか別立ち絵・専用モデルが必要か個別に判断する。

## 7. 通常モードと成人向けモード

- 通常のデスクトップ表示では不意に成人向け画像を表示しない。
- 成人向けコンテンツは別モードで明示操作により開く（販売版で検討）。
- 成人設定・生成素材の権利・DLsite分類は販売時に確認。
