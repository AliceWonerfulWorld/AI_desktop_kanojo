# Issue #30 データ駆動イベントの実装・検証

## 範囲と入口

一般向けの「お話・イベント…」を右クリック/トレイの共通メニューと既存設定へ追加。最初に一覧を開き、開始/続きからを明示的に選ぶ。起動・再起動・OS復帰・親密度上昇からイベントを自動表示しない。

初期実装は承認済みA案。左に既存PNGの全身/仮CGを切り替え、右に名前・本文・選択肢・次へを表示する。基準960×640 DIP、最小640×480 DIP（作業領域が小さければ制限）、本文18 DIP。クリーム/桜色、本文は不透明面、長い本文・選択肢は折返し/スクロールで読める。B案切替、文字サイズ設定、ログ/オート/既読スキップ/回想は実装しない。

サンプルは「ひと休みの相談」1本（会話→選択肢→お茶または読書→終了）。解放条件の確認用に親密度70を要する同じデータの別IDを配置する。サンプルは制作上の正式シナリオではなく、全年齢の動作確認用。新しいCGはコードで作った幾何図形のカップSVGのみ。[素材説明](../assets/events/README.md)。小春の既存PNGは加工しない。

## 定義・検証・進行

| 項目 | 正本・実装 |
| --- | --- |
| データ | `src/events/data/sample.json`。ID、version、title、audience、解放条件、開始ノード、ノード群 |
| ノード | ID、話者、本文、expression、effect、CG asset ID、次ノード、選択肢、endフラグ |
| スキーマ/解放判定 | `src/events/event-schema.ts`。Electron/DOM非依存。親密度と完了済みイベントIDで純粋に判定 |
| 進行 | `src/events/event-player.ts`。Main所有。一覧/再生/完了/閉鎖、revision、一時停止、チェックポイントを管理 |
| UI | `src/renderer/src/events/`。Mainが返す現在のページ/選択肢だけを描画し、本文をHTMLとして解釈しない |
| 画像 | 既存 `PngCharacterRenderer` と共通のAction/Expression。CGはasset IDの静的URL表のみ。描画ロジックとシナリオを分離 |

1ノードの本文8000 UTF-16文字、128ノード、選択肢8個、カタログ32イベントまで。IDは限定形式、話者/タイトル/選択肢の長さと型も検証する。endは次/選択を持たず、非endは次または選択肢のどちらかを持つ。開始ノード欠落、重複ID、存在しない次、到達不能ノード、台詞の循環を拒否する。イベントIDの重複、解放前提の欠落/循環も拒否する。不正なカタログは一覧を空にして失敗を閉じ込め、任意データの実行はしない。

本文はUnicodeコードポイント160文字ずつの表示ページへ分ける。元の全文を保持し、ノードと表示ページは別に扱う。選択肢は最終ページでだけ有効。未読ページから選択したり、選択待ちで次へ進めたりしない。effectはnone/gentle、後者は短い描画フェードだけで自動進行しない。OSの動きを減らす設定ではフェードを無効化。

Mainは一覧表示と開始の両方で解放条件とaudienceを評価し、未解放/未登録/異なるモードのIDを拒否する。Rendererからノード、ファイルパス、保存内容は受け取らない。コマンドには表示revisionを付け、二重発火・古い選択・古いウィンドウからの進行を拒否する。Rendererも送信中に進行ボタンを無効化する。戻る/非表示は古いrevisionや保存完了待ちで塞がない。

## 画面と日常の復帰

- 一般一覧を開いただけでは日常を止めない。再生開始時に現在の日常表示状態を取り、常駐PNGを非表示にする。表示状態に一時的な `eventPaused` 理由を追加し、既存の非表示/ユーザー停止/OSスリープと合成して残り時間を保持する。退出ではイベント理由だけを解除し、他の理由を解除しない。
- 一覧へ戻る/終了/閉じる/Escで元の表示状態を復元し、ユーザー停止やOSスリープの理由は解除しない。イベント完了は明示的な「完了して日常へ戻る」で記録して閉じる。
- 明示非表示/最小化・ロード失敗後の退避/再読込/Renderer喪失では進行を捨てて通常側へ退避する。既に保存したチェックポイントは残る。非表示中に進行しない。
- 一般イベントのblurは表示を維持して進行を休止。focusだけで再開せず、明示再開が必要。OSスリープでは一般ウィンドウも閉じて、復帰後は一覧から明示再開する。
- 入場中に日常のクリック反応・吹き出しを流さず、イベント閲覧で親密度や交流回数は増やさない。日常のクリック透過・ドラッグは既存の描画/座標処理を維持する。イベント窓は矩形入力で背後へクリックを透過しない。
- Enter/Spaceは本文にフォーカス中に次へ、ボタンは標準操作。長押しrepeatを本文送りに使わず、ホイールはスクロールだけ。画像クリックに送りを割り当てない。Escと常設の戻る/非表示は退出用。

## 保存とエラー

既存schema v1へ `events` の辞書を追加。旧セーブで未定義なら `{}` を補い、生活記憶・設定は維持。各イベントのversion、現在ノード、ページ、訪問済みノード、確定した選択ID、完了フラグを保存する。表示許可・成人確認・専用モードは保存しない。親密度・交流回数とイベント完了を混同しない。

進行時ごとに `MemorySession.eventCheckpoint` → 既存 `MemoryStore.save` の一時ファイル置換/バックアップ経路へ接続する。別のDB/保存ファイルは増やさない。保存のレコード数32件、JSON長32768文字、訪問/選択128件等の上限を検証し、既存の64KiBセーブ上限内に収める。壊れた構造は既存の破損復旧へ。スクリプトversion、開始からの経路、ページ範囲が合わない保存位置は再開不可とし、一覧から新規開始する。台本更新時はversionを上げ、安定したIDを使う。

ディスク保存は進行入力を待たせず直列キューへ渡す。保存失敗はイベント/設定画面の状態文で知らせ、確認ダイアログを毎回出したり、閉じる/非表示/終了を妨げたりしない。Mainの終了時保存失敗も同期エラーダイアログで終了を塞がない。直近の未保存分は失われうるため、再起動後は最後に保存できた位置から一覧の「続きから」で再開する。保存成功前に「ディスクへ保存完了」とは表示しない。

## #29・#31との境界

専用モードは#29の自己申告/明示操作を必須とし、確認前はイベントAPIを拒否する。確認後にだけ同じUIとエンジンをprivate audienceで利用できる。現在は専用イベントをカタログへ登録していないため専用一覧は空。成人向けの入口・素材・シナリオを通常メニューへ追加しない。日常APIへ返すイベント記録も一般向けIDのみに絞る。

#29のblur ONは専用ウィンドウ/進行を閉じ、OFFは双方を休止し明示再開を必要とする。スリープ・終了・再起動で許可は失効し、#31の専用イベントの続きへは再度確認→専用一覧→明示再開が必要。今回#31の初回イベント/実画像・#32のログ/既読機能・#33の回想を完成したとは扱わない。将来の専用素材は入場後の読み込み/権利管理を別途接続する。

## 自動検証と目視

- `npm run check`: lint/format、単体80件、型チェック、ビルド成功。追加10件は会話→選択→CG→完了、長文の全文保持、循環/不正データ/カタログ、解放条件、audience、二重送り/停止、再起動相当の再開、旧セーブ/破損/上限、保存拒否のトランザクション、限定IPC入力。
- `npm run test:events`: 一時userDataの実Electronを中断/再開/保存失敗の3プロセスで検証。未解放や不正IDで画面不変、実選択肢・PNG画素・CG/欠損代替、blur→明示再開、非表示/スリープ、通常への復元、選択/訪問/完了の保存と再起動後の一覧、非加算、保存失敗中の非表示/終了を確認。
- `npm run test:private-mode`: 確認前のイベントAPI拒否とprivate/general一覧の分離を追加。既存のblur・スリープ・再起動等も維持。
- `npm run test:smoke`, `test:character`, `test:settings`, `test:memory`, `test:styles`: 既存の日常入力/透過/トレイ、6表情、設定・保存、開発/本番CSSを回帰確認。
- ネイティブ描画キャプチャで全身PNG・選択肢・仮CG・欠損表示・640×480を目視。画像デコード、フェード完了、描画フレームを待って撮影し、古いフレームを完成画面と扱わない。

未解放/古いrevision/保存失敗のログは意図した負テスト。個人セーブは使わない。自動DOM操作・入力送出・模擬blur/powerと実OS操作は区別する。
