# DLsite販売・公開チェックリスト

> この文書は確認項目の整理であり、DLsiteの最新審査ルールを確定的に記載したものではありません。申請時点の公式規約・ガイドラインを必ず再確認してください。

## 1. 作品の方向性
- [ ] 対象キャラクターは明確に成人
- [ ] 通常モードで不意の成人向け描写が出ない
- [ ] 成人向けコンテンツは明示的に開く設計
- [ ] 作品説明と収録内容が一致
- [ ] 年齢区分・必要な表現修正をDLsiteの現行基準で確認

## 2. 生成AI・素材
- [ ] イラスト制作手法（手描き・生成AI利用など）を明確にする
- [ ] DLsiteの生成AI作品に関する現在の受付条件・申告方法を確認
- [ ] イラスト・音声・効果音・フォントの商用配布権を確認
- [ ] キャラデザイン・Live2Dモデル・外注契約の利用範囲を確認
- [ ] 利用素材の出典とライセンスを記録

## 3. 品質
- [ ] Windows用の配布形式（installer / portable）を確定
- [ ] インストール、初回起動、アンインストールを確認
- [ ] 保存、再起動、設定リセット、トレイ終了を確認
- [ ] 複数ディスプレイ、表示倍率、透明ウィンドウの操作確認
- [ ] ウイルス対策ソフトの誤検知・署名を検討
- [ ] オフライン起動・動作確認
- [ ] 動作環境・既知の制約を記載

## 4. プライバシーと安全性
- [ ] 画面・キー入力・他アプリの内容を無断取得しない
- [ ] セーブデータをローカル管理し初期化できる
- [ ] 外部送信する場合は内容・目的・同意方法を明示
- [ ] 常時前面表示をOFFにできる
- [ ] 作業中の通知や成人向け演出を無効化できる

## 5. 販売ページ
- [ ] タイトルとサークル/制作者名
- [ ] 機能説明と導入手順
- [ ] 動作環境・対応OS・制約
- [ ] 通常モードと成人向け要素の内容を正確に紹介
- [ ] 商用利用可能なスクリーンショット/紹介画像
- [ ] 価格は競合作品・素材量・制作費を踏まえて決定
- [ ] 問い合わせ先・更新履歴・バージョン番号

## 6. 公開前の最終ゲート
- [ ] 最新の販売規約・登録手順を再確認
- [ ] すべてのコンテンツ・アセットの配布権利を確認
- [ ] 他のWindows PCで起動と操作を確認
- [ ] テスターから重大なバグがないことを確認
- [ ] README・ユーザー向け操作説明と販売ページが一致

## 備考
ハッカソン参加資格・規約・期限と、DLsiteの審査条件は別に確認が必要。
