# 要件定義（MVP）

## 1. スコープ
### Must（ハッカソンMVP）
| ID | 機能 | 最低受け入れ条件 |
| --- | --- | --- |
| FR-01 | 透明・枠なしウィンドウ | Windowsのデスクトップ上に2Dキャラクターを表示 |
| FR-02 | 移動・操作 | ドラッグで移動、トレイから非表示・終了が可能 |
| FR-03 | キャラ描画 | 表情・行動の画像差分を状態で切替 |
| FR-04 | 自律行動 | 待機・読書・休憩・睡眠を自動遷移 |
| FR-05 | 時刻連動 | 朝昼夜で行動確率・挨拶が変化 |
| FR-06 | 交流 | クリックで表情・短いセリフが変化 |
| FR-07 | 関係性 | 控えめな3段階の関係性・セリフ分岐 |
| FR-08 | 生活記憶 | 親密度、起動日、累計利用時間、設定を復元 |
| FR-09 | 設定 | 前面表示・表示サイズ・自発セリフを制御 |
| FR-10 | 配布 | 開発環境のないWindowsで動作確認 |

### Should（余力があれば）
- まばたきと小さな姿勢変化
- 画面端での位置補正
- ウィンドウ透明部のクリック透過
- 時刻別セリフの種類を増やす
- 複数ディスプレイ・DPIでの使い勝手改善

### Won't（MVP対象外）
- AI生成会話、音声認識、クラウド連携
- フルLive2Dモデル前提の設計
- 3Dモデル、複数キャラクター
- 課金・アカウント・同期
- 成人向け本編イベント（販売版で別途設計）
- OSのキー入力や作業画面の監視

## 2. 非機能要件
- **安全性**: RendererにNode.jsの直接権限を与えない。IPCは必要最低限。
- **プライバシー**: オフライン優先。ログや保存データを勝手に送信しない。
- **負荷**: 常駐を前提に、不要な高頻度更新・ポーリングを避ける。
- **継続利用**: 非表示・終了・最前面解除を簡単にできる。
- **信頼性**: 異常終了後もセーブが壊れにくい。破損時に復旧可能。
- **アクセシビリティ**: 小さすぎる操作領域を避け、音・自発セリフをオフにできる。
- **互換性**: Windows 11を主な確認環境とする。他の環境は検証結果を記録。
- **権利**: 本番配布素材の商用利用権・配布条件を確認。

## 3. 画面・操作
- 常駐キャラクター表示: 透明背景の小型ウィンドウ
- 吹き出し: キャラの近くに表示し、一定時間後に消える
- トレイメニュー: 表示/非表示、設定、終了
- 設定画面: 最前面、サイズ、自発セリフの切替
- 成人向け機能: 別モード、初期状態では表示しない（販売版検討）

## 4. 完了の定義（Definition of Done）
- 機能が実機で再現できる
- 異常系（再起動、設定破損、操作連打など）を確認
- Issueのチェックリストと関連文書を更新
- ビルド・動作確認手順をREADMEへ記載
