## 1. 体験の軸と範囲

日常は透明な小春のPNGと短い吹き出しだけで「静かな同居感」を保つ。長文や選択を必要とする物語は、ユーザーが開く専用ウィンドウへ分ける。親密度や時刻によってイベントを自動表示しない。PNGを前提とし、Live2D（#15/#16/#23/#25）は保留。AI会話・音声・CG生成は今回の対象外。

- **実装済み・維持**: 日常常駐、短いクリック反応、ドラッグ、右クリック/トレイ、設定、非表示・終了、保存。
- **ユーザー承認済み（未実装）**: D1のA案、D5の専用blur自動非表示ON/OFF、D6の日常非表示・自律行動一時停止と元状態復元、D10の進行時自動保存と明示再開。
- **ユーザー承認済み（初期仕様・未実装）**: D2寸法、D3/D4入口、D7衣装UI、D8配色、D9文字。小春の承認済み外見を変更しない。

[現行画面と比較ワイヤーフレーム](08-screen-layouts.md)、[遷移・操作・レビュー項目](25-ui-interaction-design.md) を併せて読む。

## 3. モードの分離（提案）

日常の短い交流と、専用ウィンドウで読むイベントを区別する。イベントは一般向けにも使える。桜の小花柄パジャマは一般向け衣装で、時刻・親密度・衣装変更から成人向けモードへ遷移させない。

成人向けの入口は中立なラベルの専用操作から、18歳以上の自己申告と「専用モードを開く」の明示確認へ進む。自己申告は本人確認を保証しない。D5承認済み：専用画面だけフォーカス喪失時の自動非表示をON/OFF可能にする。ONは非表示・自動再表示なし、OFFは表示維持可能だが自動送り等の進行を一時停止する。初期値ONを推奨。OSスリープ・アプリ終了・再起動は設定に関係なく専用画面を終了して通常へ戻す。退出・明示非表示後の再入場詳細は補足提案として区別し、再起動後は専用再入場と確認なしに画面・ログ・CGを復元しない。詳細と例外は [状態遷移](25-ui-interaction-design.md) に集約する。

D6承認済み：イベント開始時は日常PNGを非表示にし、自律行動を一時停止する。イベント終了時はその理由だけを除き、元の停止設定・非表示・スリープを尊重する。通常表示へ戻しても強制的な挨拶を追加しない。イベント閲覧時間を親密度や交流回数に加算しない。D10承認済み：進行時に中断位置を自動保存し、戻る・閉じるで毎回の確認なしに中断する。保存失敗でも非表示・終了は妨げず、一覧の「続きから」で明示再開する。どちらも未実装の設計契約。

クリーム色を面、桜色を控えめな装飾に使う。淡い色だけで操作や状態を伝えず、文字ラベル・輪郭・選択マークを併用する。既存設定画面の雰囲気を出発点にするが、このトークン表はコードに導入しない。
