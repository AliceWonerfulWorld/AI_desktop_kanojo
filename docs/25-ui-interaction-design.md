## 1. 状態と遷移図

画面状態（日常/一覧/再生/確認/補助）と、表示可否・停止理由・衣装を別に扱う。成人向けモードと衣装は独立。下図の「専用」は成人向け専用を指す。実線/点線で実装済みを区別する代わりに、各辺に【現行】【提案】を明示する。

```text
起動 / 再起動
  └─【現行】起動表示設定 ── ON → 日常（通常PNG、保存衣装※#37後）
                         └ OFF → 非表示・トレイ待機
日常 / 非表示
  ├─【現行】右クリック/トレイ → 設定 → 閉じる → 元の表示状態
  │                               ├─【提案 #37】衣装選択 → 日常へ適用
  │                               └─【提案 #29】専用入口 → 成人自己申告
  │                                         ├ キャンセル/Esc → 設定
  │                                         └ 明示確認 → 専用一覧
  ├─【提案 #30】お話・イベント… → 一般一覧 → 明示開始 → 一般再生
  ├─【現行】非表示 ←→ トレイで表示（フォーカスを奪わない）
  └─【現行】終了 → 保存 → プロセス終了

一般一覧 / 一般再生
  ├─【提案】ログ（#32）/ 設定 → 閉じる → 同じ位置（進行は停止）
  ├─【提案】戻る / Esc / OSウィンドウ閉じる / 完了 → 日常
  └─【提案】非表示 → 再生停止・中断位置保存 → 非表示・トレイ待機

専用一覧 / 専用再生 / 専用ログ / 専用ギャラリー（#33）
  ├─【提案】戻る / Esc / OSウィンドウ閉じる / 完了 → 通常の日常
  ├─【提案】非表示 / フォーカス喪失 / OSスリープ
  │           → 専用描画・進行を停止 → 専用状態を解除 → 非表示・トレイ待機
  ├─【提案】設定 → 専用状態解除 → 通常設定（専用画面を背後に残さない）
  └─【提案】終了 / クラッシュ → 次の起動は通常の起動表示設定へ

専用からの退出・非表示・再起動後に続きへ進む場合
  設定の専用入口 → 成人自己申告を再確認 → 専用一覧 →「続きから」
  ※親密度・時刻・衣装・トレイ再表示・復帰通知だけでは専用へ戻らない。
```

一般イベントの一覧へ戻る「イベントを選び直す」は別ラベルとし、「日常へ戻る」と混同しない。専用状態で一覧へ戻る操作も可能だが、Escと「日常へ戻る」は常に通常へ離脱する。専用の全階層で共通にする。

### 遷移時の状態・保存・復帰（提案）

| 操作/事象 | 画面と進行 | 保存・復帰 |
| --- | --- | --- |
| イベント一覧を開く | 一般一覧は中立なタイトル/説明のみ。まだ日常は進行。開始時だけ日常を隠す | 未解放の開始は拒否し一覧を維持。条件を画面に示す |
| 専用入口を開く | 自己申告確認中は専用素材を読まない。確認後、専用一覧へ入る時点で日常を隠し進行停止 | 自己申告の永続スキップは採用しない案。毎回の入場で再確認 |
| イベント開始 | 日常の短い反応・吹き出しを消し、イベント停止理由を追加。イベント窓1枚、二重開始を拒否 | 入場前の日常表示状態を保持。元から非表示なら退出後も非表示 |
| 終了/中断/完了 | イベントの予約・描画・入力を停止。日常の停止理由からイベント分だけ除く | 正常終了/中断位置・完了は #30 の保存へ。完了以外で報酬/完了を加算しない |
| 非表示 | 一般/専用どちらもイベント窓と常駐キャラを隠す。専用は内容と入場状態も解除 | 再表示は通常PNGのみ。設定窓が残っても一般向け内容に限る |
| 専用中のフォーカス喪失/スリープ | 即時に専用内容を隠し、モード解除。復帰時に自動再生しない | トレイから通常表示へ。OSの他アプリへフォーカスを奪い返さない |
| 一般再生のフォーカス喪失 | 自動送り/スキップを停止、手動進行も休止。画面は維持 | 戻っても自動送りを再開せず、明示「次へ」から再開 |
| 設定/ログを開く | 一般は元の本文ページ・選択状態を保持し停止。専用の設定は先に通常へ離脱 | 一般は閉じて同じ位置、専用設定から戻っても専用再開しない |
| 保存失敗 | 中立な保存失敗表示。画面離脱・非表示を阻害しない | 最終保存済み位置からの再開になると説明。退出時に専用文言を通常通知へ持ち越さない |
| 終了/クラッシュ/再起動 | 表示状態は必ず通常。イベント窓・ログ・ギャラリーを自動復元しない | 進行ID/位置は保存可能だが、表示許可とは分離。一般も一覧から明示再開 |
| 日常へ復帰 | 保存済み最前面・サイズ・衣装・位置を尊重。強制挨拶やクリック反応の再生なし | 元の非表示/ユーザー停止/OSスリープが残れば進行を再開しない |

日常の停止は残り時間を保持する案。停止中の経過をイベント終了時にまとめて進めない。イベントを見ただけで生活の交流回数や親密度を加算せず、イベント由来の結果は #30/#31 の明示仕様で扱う。

## 2. 入力マトリクス

「現行」以外は提案。グローバルショートカットは追加しない。入力はフォーカス中の当該ウィンドウだけで受ける。

| 入力 | 日常【現行】 | 設定/衣装【既存＋提案】 | イベント【提案】 |
| --- | --- | --- | --- |
| 左クリック | 有効画素の短いクリックで短文反応 | 標準入力/ボタン。衣装確定は #37 | 本文面/次へで1ページ。画像クリックは進めない。選択肢はその候補を1回確定 |
| 左ドラッグ | 6 DIP以上で移動、終了は交流0回 | 範囲入力/スクロール、窓移動はOSタイトルバー | OSタイトルバーのみ移動。本文選択/スクロールを送りと解釈しない |
| 右クリック | 有効画素で既存メニュー | 標準動作。日常のメニューを新設しない | 専用の隠し操作を割り当てない。日常メニューは開かない |
| Enter / Space | キャラにフォーカス時メニューを開く（交流ではない） | チェック/ボタン等の確定。衣装案は候補移動と適用を分離 | フォーカス中のボタンだけを起動。本文にフォーカス時は次へ。選択待ちは次へ無効、Spaceは選択の勝手な自動確定をしない |
| Tab / Shift+Tab | キャラはフォーカス可能 | 標準順序を維持。追加欄は既存項目の後 | 日常へ戻る→非表示→本文→次へ→選択肢→ログ→設定。視覚順に合わせ、無効/未実装を飛ばす |
| 矢印 / ホイール | 独自機能なし | 範囲値/スクロール。衣装候補の上下移動は提案 | 本文/選択肢/ログのスクロール。ホイールで台詞を送らない |
| Shift+F10 / ContextMenu | 既存メニュー | 標準動作 | 専用ショートカットを追加しない |
| Esc | 独自処理なし | 既存設定は独自処理なし。新規成人確認はキャンセル | 一般ログならログ閉じる、一般再生/一覧なら日常へ。専用はログ等からでも1回で通常へ離脱 |
| OSの閉じる | 日常closeは非表示 | 設定closeは設定だけ閉じる | イベントは中断して通常へ。アプリ終了とは区別 |
| 非表示 / 終了 | 既存トレイへ常時到達可能 | 非表示はキャラ切替。設定closeと終了を区別 | 上部「非表示」で専用を含むイベントを隠す。トレイ終了で全窓終了 |
| blur / capture喪失 | ドラッグを解除 | 既存設定は値を保持 | 一般は進行休止。専用は上表の即時離脱 |

キー長押しのrepeatは送り/選択を繰り返さない。1入力を1意図として処理し、Enterでボタン確定した同じイベントが本文送りへ伝播しない。遷移・読込・保存中は次へ/選択の二重確定を拒否し、戻る・非表示は使用可能とする。

### クリック透過とフォーカス（提案の境界）

- 日常はPNG alpha hitTestと既存の透過設定を維持。OFF時は透明領域が背後操作を遮るが、そこで交流・ドラッグ・キャラメニューを始めない。透過の切替と復旧はトレイに残す。
- イベント/確認/衣装/ログ/設定の操作面は矩形の通常ウィンドウとして入力を受け、日常のclickThrough設定を引き継がない。本文・選択肢のクリックが背後アプリへ届かないことを #29/#30 で検証する。
- 明示「開始」でイベント窓へフォーカス。一般画面のログ閉じる時は呼出元ボタン、選択確定後は次の本文、画像欠損時は代替本文へ移す。フォーカスを失っただけで選択確定しない。
- 日常復帰は既存showInactiveを基本とし他アプリのフォーカスを奪わない。専用の自己申告はキャンセルへ初期フォーカスし、ダイアログ内のTab循環を検証。専用設定ボタンは通常への離脱を伴うとラベル補足する。
- OSタイトルバーに出す名前は中立な「お話・イベント」。専用画像をサムネイル/通知へ自動登録しない。OS側のウィンドウプレビューや切替時の残像を含む露出防止は #29/#34 で実機確認が必要で、設計文書だけで保証しない。
