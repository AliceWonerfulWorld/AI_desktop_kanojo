# 企画書 — デスクトップで暮らす彼女

## 1. 製品概要
- プロジェクト名: AI_desktop_kanojo（リポジトリ名）
- 仮タイトル: となりに、いる。
- ジャンル: 2Dデスクトップマスコット / 生活シミュレーション / 関係性体験
- 想定配布先: DLsite（将来的な成人向け販売を含む）
- 想定プラットフォーム: Windows（MVP）
- AI会話: 将来検討。MVPでは搭載しない方針。

## 2. コアコンセプト
**「デスクトップの片隅で、彼女は今日も暮らしている。」**

ユーザーが操作していない時間も、成人女性キャラクターが独自の行動サイクルで過ごす。PCを起動するたびに、その日の時間帯と前回までの関係性に応じて生活の続きが見える。

## 3. 提供する価値
1. **生活感**: 読書、休憩、睡眠などを自律的に行う。
2. **存在感**: まばたき、視線、表情、小さな仕草などで静かな同居感を出す。
3. **連続性**: 起動時間、交流回数、前回起動を覚えている。
4. **親しみ**: 自然な交流で距離がゆっくり縮まる。
5. **常用性**: 普段のPC作業を邪魔しない。

## 4. 対象ユーザー（仮説）
- デスクトップマスコット・キャラクター鑑賞を好むPCユーザー
- 作業中の癒しや、静かな生活感を求める人
- 恋愛要素・成人向け追加イベントに興味のある成人ユーザー

## 5. 差別化
「画面にいるキャラクター」自体は差別化にならない。
- **動作より生活演技**: 読書中に目線を上げる、眠そうにまばたきする等
- **自律性**: クリック待機だけではなく、自分で行動を選択
- **継続性**: 昨日からの時間や関係の積み重ね
- **数字を見せすぎない関係性**: UIの好感度数値よりセリフや表情の変化を優先

## 6. UX原則
- ユーザーが放置してもキャラクターの生活は成立する。
- 起動しなかったことへのペナルティは設けない。
- 自発的な会話・通知は控えめ、設定で停止可能。
- 不意に成人向け描写を出さない。通常時は安全な表示。
- 個人の作業内容、キー入力、画面を勝手に収集しない。
- 対象キャラクターは明確に成人として設定する。

## 7. ハッカソン成功の定義
- 透明なデスクトップ上でキャラクターが見える
- 現実の時刻に合わせて自律的に行動が変わる
- クリックで反応し、小さな関係性の変化が起きる
- アプリを再起動しても生活記録が残る
- Windowsで他者が実際に試せる

## 8. 企画上の未決事項
- キャラクターの名前・年齢・性格・生活習慣・口調
- イラスト制作方法と商用ライセンス
- 関係性段階の演出と台本
- 成人向けコンテンツの具体的な内容・表現方法
